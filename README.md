## データの性質と権利について / About Data and Rights

本リポジトリで公開しているデータセットに含まれるテキスト断片は、音楽雑誌『ADLIB』（スイングジャーナル社刊）の記事を対象とした自然言語処理（構造トピックモデル）および時系列因果分析（Granger Causality Test）の研究過程で生成されたものです。

- 利用目的: 学術研究における分析結果の妥当性を検証するための「引用（Citation）」および「証拠提示」を目的としています。

- プライバシー配慮: 元データに含まれる個人情報（氏名、住所、電話番号等）は、自動処理により [個人情報] というタグに置換・匿名化しています。

- 権利の帰属: 元となる記事の著作権は、各記事の執筆者および出版社に帰属します。本データセットは雑誌そのものの代替となるものではありません。

もし権利者の方で、本データの公開に懸念がある場合は、下記連絡先までご連絡ください。速やかに適切な対応（該当箇所の削除等）を行います。

The text snippets included in this dataset are generated solely for the purpose of academic citation and verification of the topic modeling analysis. Personal information has been anonymized.
